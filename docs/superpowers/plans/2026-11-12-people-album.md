# 人物册 Implementation Plan

**Goal:** 将归图人物升级为分组肖像册，合并原有八位与新增七位，共十五位。
**Architecture:** Astro 静态页面，人物与图源集中于 `src/data/people.json`，首页与二级页共用。复用现有主题令牌，不增加依赖或客户端脚本。
**Approved design:** 本次对话中确认的「我所欣赏的人」分组肖像册；用户授权按判断落地。

## Constraints
- 五组：导演、个人成长、演员、作家、创作者；保留所有原有人物。
- 事实身份、代表作品与内容入口可查证；不虚构用户欣赏理由。
- 图片本地保存，保留来源、作者与已知许可信息。播客允许使用官方节目封面。
- `/guide/people` 由专用静态页面接管，动态路由排除此项。
- 归图首页简洁预览与完整人物页入口；所有人物由同一数据源展示。

## Tasks

- [x] 建立人物数据与分组页面，原 Markdown 同步名单，首页改成轻量预览。

## Verification focus
图片真实有效、十五位无遗漏、来源链接与锚点有效、路由唯一、窄屏不溢出、暗色文字可读。
项目约定以构建和生成 HTML 检查 Astro 展示层，不增加镜像实现的单元测试。
