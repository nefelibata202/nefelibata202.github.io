以下精选自知识库的高优先级缺口，共 **31** 个领域 **53** 条，知识库上次更新：2026-08-22。

## AI工程与LLM应用

- [ ] 整组偏「读来的范式综述」，缺我自己搭 loop / harness 的一手实践笔记——我那套 digest/lint 命令就是个人版 loop 的雏形，值得沉淀一篇「我的自动化踩坑」。

## 专注力与注意力

- [ ] 走神到什么程度该拉回？分野已知是「是否失控且反刍」，但多久算失控、反刍到什么程度算病理，至今没有判据——这是注意力主题里唯一真正悬而未决的分歧。

## 个人效率系统核心洞见

- [ ] 时间估算完全空白。「估错工作量」是我周复盘里的法定死因之一，说明这是真实痛点，但库里没有任何一篇讲规划谬误或估算方法。
- [ ] 缺「什么都不做」的正当性。整页高效导向，没有一篇处理休息、留白、主动降速——「拒绝的艺术」只覆盖了对外说不，没覆盖对自己说够了。

## 个人知识管理

- [ ] 全组重"收集/取舍"，轻"回顾/复用"——六弱点里的"健忘（缺复盘触发器）"没有对应解药笔记（间隔重复、Dataview 复盘看板值得补一篇）。

## 亲密关系与择偶

- [ ] 依恋理论整块缺席。安全型/焦虑型/回避型是解释亲密关系模式最主流的框架，却一篇没有——而「恋爱脑的两种类型」里的两种成因其实高度贴合焦虑型与回避型。
- [ ] 只有起点没有维系。现有笔记几乎全在讲吸引与配对，长期关系怎么维持（激情衰减、共同叙事、日常仪式）一篇没有。

## 人际沟通方法论

- [ ] 倾听技巧仍偏薄——非暴力沟通 覆盖"怎么表达"、积极聆听 覆盖"怎么听"，但两者之间「听完之后怎么回应」（复述、澄清、共情式回应）仍缺专篇

## 决策与判断

- [ ] 「安全边际」的留余地思维能否系统迁移到非投资决策——职业、关系、时间投入？目前只活在投资语境里。

## 啤酒里的历史

- [ ] 中国与东亚啤酒史完全空白（青岛、燕京的殖民起源），可补一篇与欧洲线形成东西对照。

## 学习与认知

- [ ] 记忆与遗忘只在反面地图里出现过。间隔重复、检索练习、遗忘曲线这些有大量实证支持的机制没有独立笔记——而这正是我那套抽考机制的理论底座。
- [ ] 迁移（transfer）问题没碰。学会 A 领域的东西能不能用到 B，是「包围式学习」与「快速自学一个新领域的方法」隐含却从未点明的核心难题。

## 心理健康与内在成长

- [ ] 社交技能因技术而萎缩描述了问题，但神经可塑性——数字化萎缩之后是否可逆？如何主动重建？——尚无对应笔记。

## 心理韧性与情绪调节

- [ ] 「课题分离」「控制二分法」「因上努力果上随缘」讲的是同一件事的三个来源（阿德勒/斯多葛/佛家），但三者之间没人说清差别到底在哪。

## 思维模型工具箱

- [ ] 概率与统计直觉整簇缺失。贝叶斯更新、基础比率、大数定律这些最常用的量化思维工具一篇没有。
- [ ] 模型之间缺少「什么时候用哪个」的元层。几十条模型平铺成簇，但面对具体问题该抽哪把刀，没有一篇导航笔记——这是工具箱变大后的必然痛点。
- [ ] 反面清单缺席。每个模型的适用边界与失效场景没被记录，容易把模型当万能钥匙。

## 成瘾与习惯的神经机制

- [ ] 已知「追血清素不追多巴胺」，但具体如何提升血清素水平（运动/深度连结/心流的非药物操作）尚无对应笔记。

## 户外跑步运动

- [ ] 训练计划整块缺失。有姿势、有热身、有力量，但配速区间、周跑量、进阶节奏、恢复日安排一篇没有——知道怎么跑好一步，不知道怎么规划一个训练周期。

## 批判性思维

- [ ] 缺「如何构建（而非只拆解）一个好论证」的正向笔记——目前全部偏「找毛病」。

## 投资领域知识

- [ ] 手写区那四只长期 ETF（电子龙头/新能源/军工龙头/芯片）相关性有多高？这是不是伪分散？
- [ ] 基本面何时算变坏到该走人？「伟大公司的四个特征」里哪一条破了算致命，没有答案。

## 拖延与行动启动

- [ ] 「停不下来」这一侧几乎空白。拖延不只是启动困难，还有退出困难（自动播放、集尾悬念专为阻止你停下而设计），但没有一篇专讲「如何结束一个正沉浸的活动」。
- [ ] 缺「执行意图 / if-then 预案」专篇。提前写好「如果发生 X，我就做 Y」是拖延干预里证据最强的手法之一，却只以一句话寄居在别篇里。

## 摄影构图与技巧

- [ ] 光线整块缺席。顺光/逆光/侧光、黄金时刻与蓝调时刻、阴天与硬光——这些对成片影响不亚于构图的变量一字未提。

## 欧亚文明交汇带

- [ ] 知识回流欧洲之后「怎么消化」仍是断头。从科尔多瓦到托莱多翻译院这条链已很完整，但经院哲学、大学制度、文艺复兴的承接一篇没有。
- [ ] 什叶—逊尼分野尚无专篇。基督教一侧的分裂已写透，伊斯兰内部的分野却只散见于零星案例。
- [ ] 「技术遭遇既得利益抵抗」这条机制只有一个样本（佛罗伦萨行会禁用阿拉伯数字）。火药、印刷术、罗盘东传时是否走过同样的路，无对照。

## 生活事务

- [ ] 五簇分布不均，理财实务只有零散几条（保险/消费），缺"个人记账/预算"这类基础理财实务笔记。

## 生活哲学

- [ ] 「衰老与失去」整条缺席。父母老去、身体衰退、朋友散场这些真会发生的事，没有任何笔记接住。
- [ ] 金钱与幸福的关系无专篇。幸福公式讲期望管理、SPIRE 讲五维，唯独收入与财务安全这个最现实的变量被绕开了。

## 短视频与内容创作

- [ ] 「三秒钩子」与「蒙太奇叙事」的冲突无人正面处理。一边要求前三秒独立留人，一边要求铺垫与节奏——短视频里怎么两者兼得？
- [ ] 缺一篇「选题从哪来」。现有笔记都在讲「拿到选题后怎么做」，没有一篇讲选题挖掘——而这通常才是内容账号的真瓶颈。

## 社交媒体与心理

- [ ] 「结构决定论 vs 个体差异」这个矛盾无人裁决。一派说媒介形式决定后果，一派说后果因人而异——这直接决定该不该戒社交媒体。
- [ ] 没有一篇讲「怎么用好」。现有笔记绝大多数是诊断与警告，社媒作为工具的正向用法（弱连接、信息获取、人脉网络）完全缺席。
- [ ] 平台机制层空白。推荐算法怎么工作、为什么高光内容更容易被分发、参与度优化如何反向塑造创作者行为——全库无笔记。

## 社会观察

- [ ] 五条脉络里唯独缺「经济」。阶层、权力、认知、媒介、时事都有，但通胀、就业、房产、人口这些最直接塑造生活的结构性变量没有独立笔记。
- [ ] 缺少「我不同意」的记录。整页立场相当一致（结构决定论），却没有任何一篇记录反例或对这套框架的有力反驳——这是回音壁风险。

## 精力与认知的生理基础

- [ ] 为什么老年人睡眠时间更短？这是睡眠机制笔记里悬而未决的问题。
- [ ] 营养/饮食对精力的影响完全空白（ATP→葡萄糖只在睡眠机制里一带而过）

## 精酿故事馆

- [ ] 酵母缺一篇。四大原料里已有麦芽、啤酒花、水，独缺酵母——而它恰恰是决定艾尔/拉格分野的那一个。
- [ ] 缺陷风味（off-flavor）无系统笔记。双乙酰、乙醛、氧化味等品鉴基本功没有成篇，目前只有日光臭一例。

## 职场

- [ ] 「怎么把活干好」整块缺失。现有笔记分别管拿位置、选方向、带人，唯独日常执行——项目推进、优先级、跨部门对齐——没有笔记，而这占了工作时间的绝大部分。
- [ ] 职业倦怠与止损没碰。「什么信号出现时该走」的判断标准是空的。
- [ ] AI 对职业路径的冲击未被记录。这是当下最该有观点的一块，目前完全沉默。

## 运动健康

- [ ] 睡眠整块缺席，而它是所有机制的前置条件。睡眠结构、时长、入睡策略一篇没有。
- [ ] 力量训练只有「抗旋转」这一个概念。渐进超负荷、动作模式（推/拉/蹲/铰链）、组次安排等训练学基础全缺。

## 运营

- [ ] 转化漏斗整条缺失。有「怎么被看见」也有「以成交为准」的标尺，但中间「看见→下单」的环节（详情页、定价、信任建立、复购）一篇没有。
- [ ] 私域与用户运营空白。社群、会员、复购、召回，全库零篇。

## 问题拆解与创新方法

- [ ] 「评估」一段最弱。A/B 测试、最小可行验证、假设检验这些真正用来判断方案好坏的方法全无。
- [ ] 约束条件下的创新没碰。现有方法讲的是打开思路，但真实项目里创新总在预算/时间/技术的硬约束下发生，这一面空白。

## 阶层与社会结构

- [ ] 只有固化机制，没有流动机制。现有笔记都在解释「为什么上不去」，但「谁上去了、靠什么上去的」一篇没有。
- [ ] 中国本土样本缺席。有韩国与印度的案例，唯独离自己最近的城乡二元、户籍、高考制度没有笔记。
