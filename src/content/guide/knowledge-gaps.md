## AI工程与LLM应用

## 专注力与注意力

- [ ] 走神到什么程度该拉回？分野已知是「是否失控且反刍」，但多久算失控、反刍到什么程度算病理，至今没有判据——这是注意力主题里唯一真正悬而未决的分歧。

## 个人效率系统核心洞见

- [ ] 时间估算完全空白。估错工作量是我周复盘里的法定死因之一，说明这是真实痛点，但库里没有任何一篇讲规划谬误或估算方法。
- [ ] 缺少「什么都不做」的正当性。整页都是高效导向，没有一篇处理休息、留白和主动降速，学会对别人说不之外，还没学会对自己说够了。
- [ ] 任务管理系统怎么搭没有笔记。心态、专注、复盘都讲了，但周计划、看板这类系统层的内容没有，而我自己正在用的周攻坚循环就是一套自建系统，值得沉淀下来。
- [ ] 纠错循环在日常工作里怎么落地。把想法到验证的时间缩短这个道理来自研究场景，换到运营和学习上对应的具体做法是什么，还没想清楚。

## 个人知识管理

- [ ] 全组重"收集/取舍"，轻"回顾/复用"——六弱点里的"健忘（缺复盘触发器）"没有对应解药笔记（间隔重复、Dataview 复盘看板值得补一篇）。

## 亲密关系与择偶

- [ ] 依恋理论整块缺席。安全型/焦虑型/回避型是解释亲密关系模式最主流的框架，却一篇没有——而「恋爱脑的两种类型」里的两种成因其实高度贴合焦虑型与回避型。
- [ ] 只有起点没有维系。现有笔记几乎全在讲吸引与配对，长期关系怎么维持（激情衰减、共同叙事、日常仪式）一篇没有。

## 人际沟通方法论

- [ ] 倾听技巧仍偏薄——非暴力沟通 覆盖"怎么表达"、积极聆听 覆盖"怎么听"，但两者之间「听完之后怎么回应」（复述、澄清、共情式回应）仍缺专篇

## 决策与判断

- [ ] 安全边际的留余地思维能不能系统地迁移到非投资决策上，比如职业、关系、时间投入。目前它只活在投资语境里。
- [ ] 决策做完之后怎么复盘。结果好不等于决策好，怎么把决策质量和运气分开看，库里没有一篇处理。
- [ ] 都是一个人的决策。几个人一起做决定时偏误怎么叠加、怎么设计流程来对冲，完全没有涉及。

## 啤酒里的历史

- [ ] 中国与东亚啤酒史完全空白（青岛、燕京的殖民起源），可补一篇与欧洲线形成东西对照。

## 啤酒风格与品鉴

- [ ] 酸啤这一整支没有进来。拉比克、古斯、柏林酸小麦这类靠野生酵母和乳酸菌的风格，既不在艾尔篇也不在拉格篇里，是目前分类树上最大的一块空白。
- [ ] 拉格一侧只有皮尔森展开成篇。琥珀拉格、深色拉格、博克这些风格在分类里被点了名，却没有各自的特征描述，和艾尔四个族系的厚度不对等。
- [ ] 英式淡色艾尔、赛松、比利时金色艾尔都只有一个名字。它们各自的风味特征和代表酒款还没写。
- [ ] 侍酒只写了倒法，没有温度和杯型。不同风格该在几度喝、用什么杯子、为什么，是品鉴里很实用却还空着的一块。
- [ ] IBU 只说了「看平衡、别迷信数值」，没说怎么看。苦度和麦芽甜度之间的平衡怎么判断，值得单独弄清楚。
- [ ] 品鉴四维只有框架，没有一次实际的品饮记录。拿几款酒按四维各写一句，才知道这把尺好不好用。

## 学习与认知

- [ ] 记忆与遗忘没有成篇。间隔重复、检索练习、遗忘曲线这些有大量实证支持的机制，库里没有独立笔记，而这正是我那套抽考机制的理论底座。
- [ ] 迁移问题没碰。学会一个领域的东西能不能用到另一个领域，是包围式学习和创造者视角都隐含却从未点明的核心难题。
- [ ] 自学时反馈从哪里来。几个学习闭环都把反馈放在最后一环，但没有老师的时候怎么给自己制造可靠的反馈，没有一篇回答。
- [ ] 学不会时怎么诊断。全页都在讲怎么学对，没有一篇讲卡住时如何判断是缺前置知识、缺框架，还是缺练习量。
- [ ] 动机怎么维持。从目的入手可以点火，相信自己做得到可以起步，但学到一半火灭了怎么办，仍然是空的。

## 心理健康与内在成长

- [ ] 社交技能因技术而萎缩描述了问题，但神经可塑性——数字化萎缩之后是否可逆？如何主动重建？——尚无对应笔记。

## 心理韧性与情绪调节

- [ ] 课题分离、控制二分法、因上努力果上随缘讲的像是同一件事，分别来自阿德勒、斯多葛和佛家，但三者的差别到底在哪里，我还说不清。
- [ ] 倦怠和抑郁怎么区分，什么时候该找专业帮助。倦怠被定性为职业现象而不是病，可两者的症状有重叠，界线在哪没有笔记。
- [ ] 创伤后成长只有方向，没有可落地的步骤。机制已经有了，从安全感到身份重建之间具体做什么仍是空白。
- [ ] 什么样的谈话才能带来情感上的突破。单纯倾诉会泄掉改变的动力，那有效的谈法具体长什么样，没有对应笔记。

## 思维模型工具箱

- [ ] 概率与统计直觉仍然很薄。除了贝叶斯式的动态更新，基础比率、回归均值、大数定律这些最常用的量化思维工具一篇都没有。
- [ ] 模型之间缺少「什么时候用哪个」的导航。第一性原理、MECE、3C 三把工具已经有了协同说明，但工具箱里其余几十条模型面对具体问题该抽哪一把，还没有同样的梳理。
- [ ] 反面清单缺席。每个模型的适用边界与失效场景没有被记录，容易把模型当成万能钥匙。
- [ ] 「先做再说」和「先想清楚」各自适用于什么场合。一边说别想了先动手，一边说多数人的问题是不思考，两条都对，但分界线在哪里我还没写下来。

## 成瘾与习惯的神经机制

- [ ] 彻底隔离和限额娱乐，什么时候用哪个。一种主张是先完全断开高强度刺激一段时间，另一种是保留娱乐但收成整块，我还没有判断自己该用哪种的标准。
- [ ] 复发了怎么办。四步流程讲了怎么拆旧回路，但掉回去之后怎么处理、要不要从头再来，没有一篇回答。
- [ ] 这套方法的样本几乎都是手机、小说和短视频。它能不能迁移到消费、饮食、社交这些别的成瘾上，尚未展开。
- [ ] 这些神经机制说法的证据等级不清楚。多篇笔记用了很精确的表述，比如受体水平提升多少、哪个脑区负责关联编码，却没有标出处，哪些是定论、哪些只是通俗讲法需要核一遍。

## 户外跑步运动

- [ ] 训练计划整块缺失。有姿势、有热身、有力量，但配速区间、周跑量、进阶节奏、恢复日安排一篇没有——知道怎么跑好一步，不知道怎么规划一个训练周期。

## 批判性思维

- [ ] 缺「如何构建（而非只拆解）一个好论证」的正向笔记——目前全部偏「找毛病」。

## 技术分析与交易纪律

- [ ] RSI 的超卖信号和「下行趋势不抄底」怎么并用。一个说跌多了可能反弹，一个说 4 到 6 点钟方向别碰，两者冲突时以谁为准，我还没有规则。
- [ ] 只有止损，没有止盈。除了连续涨停股的移动条件单，正常持仓赚到多少该走、怎么分批走，没有任何一篇回答。
- [ ] 仓位管理不成体系。只在尾盘战法里出现过单笔不超过短线账户 5% 这一条，总仓位、分散度、加减仓规则都还没有。
- [ ] 均线、量比、换手率、分时均线这些基础概念没有各自的笔记。它们在尾盘选股法的九个条件里被直接使用，却没有地方解释它们本身是什么。
- [ ] 测试仓 -15% 止损线的依据。这个数字是怎么来的、是否该随波动率调整，目前只是一条照录的规则。
- [ ] 尾盘选股法约定记满 20 笔再评判，但样本记录还不存在。没有样本，这套战法就一直停在未验证状态。

- [ ] 基本面何时算变坏到该走人？「伟大公司的四个特征」里哪一条破了算致命，没有答案。

## 拖延与行动启动

- [ ] 「停不下来」这一侧几乎空白。拖延不只是启动困难，还有退出困难（自动播放、集尾悬念专为阻止你停下而设计），但没有一篇专讲「如何结束一个正沉浸的活动」。
- [ ] 缺「执行意图 / if-then 预案」专篇。提前写好「如果发生 X，我就做 Y」是拖延干预里证据最强的手法之一，却只以一句话寄居在别篇里。

## 摄影构图与技巧

- [ ] 光线整块缺席。顺光/逆光/侧光、黄金时刻与蓝调时刻、阴天与硬光——这些对成片影响不亚于构图的变量一字未提。

## 欧亚文明交汇带

- [ ] 知识回流欧洲之后怎么被消化，只补上了大学这一环。经院哲学怎么吸收亚里士多德、文艺复兴又怎么接手，仍然一篇没有。
- [ ] 什叶与逊尼的分野尚无专篇。基督教一侧的分裂已经写得很透，伊斯兰内部的分野却只散见于零星案例。
- [ ] 被推翻的通俗说法记了十几个，但推翻它们的研究自己有多可靠、学界是否还在争，只有黑死病那一篇标了出来。翻案本身也需要被核一遍。
- [ ] 这条带子几乎都是从欧洲和中东往东看。同一批事件在中国和印度一侧怎么被记录、怎么被理解，目前只有零星几篇。
- [ ] 技术碰上既得利益抵抗的例子仍只有一个，就是行会禁用阿拉伯数字。火药、印刷术、罗盘西传时有没有走过同样的路，没有对照。
- [ ] 普通人的视角几乎是空的。女性只出现在宫廷、书信和一位写史的公主身上，工匠、市集、农妇这一层没有任何笔记。

## 生活事务

- [ ] 五簇分布不均，理财实务只有零散几条（保险/消费），缺"个人记账/预算"这类基础理财实务笔记。

## 生活哲学

- [ ] 「衰老与失去」整条缺席。父母老去、身体衰退、朋友散场这些真会发生的事，没有任何笔记接住。
- [ ] 金钱与幸福的关系无专篇。幸福公式讲期望管理、SPIRE 讲五维，唯独收入与财务安全这个最现实的变量被绕开了。

## 短视频与内容创作

- [ ] 「三秒钩子」与「蒙太奇叙事」的冲突无人正面处理。一边要求前三秒独立留人，一边要求铺垫与节奏——短视频里怎么两者兼得？
- [ ] 缺一篇「选题从哪来」。现有笔记都在讲「拿到选题后怎么做」，没有一篇讲选题挖掘——而这通常才是内容账号的真瓶颈。

## 社交媒体与心理

- [ ] 「结构决定论 vs 个体差异」这个矛盾无人裁决。一派说媒介形式决定后果，一派说后果因人而异——这直接决定该不该戒社交媒体。
- [ ] 没有一篇讲「怎么用好」。现有笔记绝大多数是诊断与警告，社媒作为工具的正向用法（弱连接、信息获取、人脉网络）完全缺席。
- [ ] 平台机制层空白。推荐算法怎么工作、为什么高光内容更容易被分发、参与度优化如何反向塑造创作者行为——全库无笔记。

## 社会观察

- [ ] 经济这条线仍然很薄。除了石油与美债那一条链，通胀、就业、房产、人口这些最直接塑造生活的结构性变量没有独立笔记。
- [ ] 权力总纲还没有落到当代。隐蔽的思想权在平台、算法、行政里具体怎么运行，只有历史案例和零散观察，缺一篇把它接到今天的笔记。
- [ ] 缺少「我不同意」的记录。整页立场相当一致，都偏向结构决定论，却没有任何一篇记录反例或对这套框架的有力反驳，有回音壁风险。
- [ ] 宗教只以组织和政治的面目出现。教派怎么分化、怎么和朝廷打交道都有了，但信仰对普通人意味着什么、为什么有人信，库里没有。
- [ ] 道教一束只有一个来源。五篇同日入库、全部待复阅，需要第二批独立材料才能判断哪些说法站得住。

## 精力与认知的生理基础

- [ ] 昼夜节律本身没有笔记。午夜后大脑的变化、睡眠拖延都建立在它之上，但时型、光照、褪黑素这些基础我还没整理过。
- [ ] 为什么老年人睡眠时间更短。这是睡眠机制那篇里一直悬着的问题。
- [ ] 营养和饮食对精力的影响完全空白。能量从葡萄糖到 ATP 只在讲睡眠时一带而过。
- [ ] 几种分钟级恢复手段怎么选。小睡、非睡眠深度休息、出去走一走各自适合什么时候、能不能叠加，没有一篇放在一起比较。

## 精力管理系统

- [ ] 怎么知道自己今天的精力处在什么水位。四个维度和收支的道理都有了，但没有一篇说怎么观察和记录，从而在透支之前就发现。
- [ ] 组织不变的时候，个人还能做什么。倦怠的根源大半在工作量、资源、自主权这些组织变量上，个人层面的调整能走多远、到哪一步该考虑离开，没有答案。
- [ ] 营养和饮食对精力的影响完全空白。睡眠、运动、休息都有笔记，吃什么、什么时候吃却一字未提。

## 精酿故事馆

- [ ] 酵母缺一篇。四大原料里已有麦芽、啤酒花、水，独缺酵母——而它恰恰是决定艾尔/拉格分野的那一个。
- [ ] 缺陷风味（off-flavor）无系统笔记。双乙酰、乙醛、氧化味等品鉴基本功没有成篇，目前只有日光臭一例。

## 职业发展与个人竞争力

- [ ] 35 岁以后的路径几乎是空的。三阶段只用一句「整合资源、让势能兑现」带过，没有任何案例说明这一步具体长什么样。
- [ ] 动机自测只靠回忆「最成功和最挫败的一件事」。有没有更可验证的办法判断自己的成就、影响、亲和动机各有多高，还没弄清楚。
- [ ] 专家路线和管理路线怎么选、什么时候选。动机配比给了方向，但真到岔路口时的判断依据和代价没有写。
- [ ] AI 时代的能力三层只针对技术岗。运营、外贸这类非技术岗位对应的三层是什么，没有答案。
- [ ] 个人形象被排在比聪明勤奋更稀缺的位置，却没有任何一篇说它具体指什么、怎么经营。
- [ ] 跳槽和谈薪的时机判断。安全网那篇提到网织密后更敢提加薪，但什么信号说明该提、该走，没有成篇。

## 职场

- [ ] 「怎么把活干好」整块缺失。现有笔记分别管拿位置、选方向、带人，唯独日常执行——项目推进、优先级、跨部门对齐——没有笔记，而这占了工作时间的绝大部分。
- [ ] 职业倦怠与止损没碰。「什么信号出现时该走」的判断标准是空的。
- [ ] AI 对职业路径的冲击未被记录。这是当下最该有观点的一块，目前完全沉默。

## 英语

- [ ] 雅思写作 Task 2 还没有任何笔记。书信那篇自己说 Task 2 权重是 Task 1 的两倍、时间要留给它，但议论文怎么搭结构、怎么在限时内写完，库里是空的。
- [ ] 口语只有 Part 2。Part 1 的短答和 Part 3 的抽象讨论怎么应对、和 Part 2 素材如何衔接，还没有整理。

- [ ] 词汇怎么积累没有成篇。同义替换对抄下来之后如何复习、如何让它在听的瞬间被认出来，目前只有「记下来」这一步。

## 运动健康

- [ ] 睡眠整块缺席，而它是所有机制的前置条件。睡眠结构、时长、入睡策略一篇没有。
- [ ] 力量训练只有「抗旋转」这一个概念。渐进超负荷、动作模式（推/拉/蹲/铰链）、组次安排等训练学基础全缺。

## 运营

- [ ] 转化漏斗整条缺失。有「怎么被看见」也有「以成交为准」的标尺，但中间「看见→下单」的环节（详情页、定价、信任建立、复购）一篇没有。
- [ ] 私域与用户运营空白。社群、会员、复购、召回，全库零篇。

## 问题拆解与创新方法

- [ ] 「评估」一段最弱。A/B 测试、最小可行验证、假设检验这些真正用来判断方案好坏的方法全无。
- [ ] 约束条件下的创新没碰。现有方法讲的是打开思路，但真实项目里创新总在预算/时间/技术的硬约束下发生，这一面空白。

## 阶层与社会结构

- [ ] 只有固化机制，没有流动机制。现有笔记都在解释「为什么上不去」，但「谁上去了、靠什么上去的」一篇没有。
- [ ] 中国本土样本缺席。有韩国与印度的案例，唯独离自己最近的城乡二元、户籍、高考制度没有笔记。
